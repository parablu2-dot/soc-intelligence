# 서사 함정 유형 분류

`NarrativeTrapCase.trap_type`(자유 텍스트 필드, `scripts/narrative_trap_case.py`)에 실제로 쓰이는 값들의
정의를 모아두는 문서. baseline notes와 동일한 git-as-storage 패턴 — 빌드 파이프라인에 연결되지 않은
순수 참고 문서(런타임 미개입).

## 기존 유형 (①②③, 코드 주석 origin — 세부 판별 질문은 아직 미문서화)

- **①분모은폐형** — 비율/배수(%, x배) 서술에서 기준값(베이스)이 생략되어 실제 규모를 가늠할 수 없게 되는 패턴.
- **②침묵독해형** — 공식 발표에서 특정 사실이 언급되지 않는 것 자체를 신호로 해석하는 패턴.
- **③기업문서vs시장서사** — 기업 공식 문서(IR/공시)와 시장에 유통되는 서사 사이의 괴리.

(위 세 유형은 `narrative_trap_case.py`의 인라인 주석에서 최초 등장. 판별 질문·승격 이력은 이 문서 신설 시점에는
소급 기록되지 않음 — 다음에 각 유형 관련 사례가 나올 때 이 문서에 채워 넣을 것.)

### ④단일소스 다중매체 에코형 (single_source_multi_echo) — draft, 2026-08-08 등록

**정의**: 하나의 익명/미확정 원출처가 여러 매체명으로 재보도되면서 마치 독립 교차검증된 것처럼 보이는 경우 —
서사 자체는 존재하나 근거의 개수가 아니라 근거의 "복제 횟수"만 늘어난 상태.

**판별 질문 3개**:
1. 각 매체가 독립 취재원을 명시하는가, 아니면 전부 동일 1차 소스(또는 서로를 인용)로 수렴하는가
2. 원출처가 "Reportedly"·"~로 알려짐" 같은 미확정 어휘를 쓰는가
3. 매체 수가 늘수록 확신도가 올라간다는 착시가 스코어링/사람 판단에 실제로 반영되고 있는가

**승격 기준**: 독립 사례 2건 이상 확보 시 정식 유형으로 승격 (①②③과 동급 대우).
