# 세션 핸드오프 — SoC대시보드/1b googlenews 업체 태깅

## 목표 (1~2줄)
PR #5로 전용 크롤러를 제거한 7개 업체(qualcomm/broadcom/marvell/smic/ase/amkor/jcet)가 업체별 뷰에서 비지 않도록, googlenews 신호에 언급 업체를 결정론적으로 태깅한다 (확정 실행 순서의 2단계 "1b").

## 확정된 결정사항 (근거 한 줄씩)
- company='googlenews'는 그대로 두고 별도 필드 `mentions`(슬러그 리스트)로 부착 — dedup_gate의 axis+company 스코프·false-merge 방지 원칙을 건드리지 않기 위해.
- 태깅은 크롤러가 아니라 `export_refined.py`에서 수행 — 기존 canonical_nodes 전체에 자동 적용돼 별도 백필이 필요 없음.
- 매칭은 정규식만 사용(LLM 없음), 짧은 약어(ASE/AMD/SMIC)는 대소문자 구분+단어 경계 — 런타임 토큰 0 원칙, 오탐 방지.
- 대상은 googlenews만 (trendforce/etnews 제외) — 결정 범위가 googlenews였고, etnews는 한국어 업체명 사전이 없음.
- company_strategy.py는 googlenews를 가짜 업체로 요약하지 않고 언급 업체로 헤드라인 분배 — 7개 업체 월간 요약 카드 유지.
- 로컬 export 산출 데이터는 커밋하지 않고 되돌림 — CI 자동 커밋과 충돌 방지.
